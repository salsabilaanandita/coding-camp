# Expense & Budget Visualizer

A mobile-friendly web app for tracking daily spending. It shows the total balance, a scrollable list of transactions, and a pie chart of spending by category. Built with HTML, CSS, and vanilla JavaScript. All data stays in your browser (Local Storage).

## Features

- Add a transaction with Item Name, Amount, and Category (Food, Transport, Fun), with validation
- Scrollable transaction list with delete
- Total balance at the top, updated automatically
- Pie chart of spending by category (Chart.js), updated automatically
- Data saved in Local Storage and restored on reload
- Sort transactions by newest, amount, or category
- Highlight spending over a set limit
- Dark/light mode toggle

## Tech Stack

- HTML, CSS, vanilla JavaScript (no framework)
- [Chart.js](https://www.chartjs.org/) via CDN
- Browser Local Storage (no backend)
